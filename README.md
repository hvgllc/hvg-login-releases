# HVG Login

Bộ cài và bản cập nhật của HVG Login, ứng dụng quản lý hồ sơ trình duyệt của Havi Group.

- Bộ cài mới nhất nằm ở trang [Releases](https://github.com/hvgllc/hvg-login-releases/releases/latest).
- App đã cài tự kiểm tra bản mới tại đây (`latest.json`) và chỉ cài bản mang chữ ký phát hành của Havi Group.
- Cần tài khoản do quản trị viên cấp để sử dụng.

Repo này chỉ chứa bản phát hành, không chứa mã nguồn.
